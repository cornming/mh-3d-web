# 3D 魔物獵人 Web 原型 (Monster Hunter 3D Web)

基於 **Three.js** 與原生 **Web Audio API** 開發的純前端 3D 動作狩獵遊戲原型。免安裝任何 Node 模組或建置工具，開箱即玩！

---

## 🌟 核心特色與技術亮點

本專案融合並借鏡了 GitHub 社群多款經典 3D 動作與 WebGL 專案（如 `simondevyoutube/Quick_3D_RPG`、`honzaap/SlashSaber`、`elmarjens/three-js-fighter-game` 等）的精髓，並深度還原魔物獵人（Monster Hunter）的靈魂戰鬥體驗：

1. **極致打擊感（Hitstop / 卡肉感 ＆ 螢幕微震）**
   - 劈中肉質時具備數十毫秒的瞬間邏輯定格（Hitstop）與相機隨機震顫，完美呈現大劍斬擊的厚重手感。
2. **純程式化 Web Audio 音效合成器**
   - 不依賴外部 `.mp3` / `.wav` 音檔，完全使用瀏覽器原生 Web Audio API 合成：
     - 大劍破空斬擊聲、輕/重攻擊肉質撞擊音
     - 魔物震天咆哮嘶吼聲（Roar）
     - 翻滾風聲、回覆藥咕嚕聲、砥石磨刀金屬脆鳴
3. **魔物 AI 狀態機與經典機制**
   - **震天龍吼（Roar）**：血量降至 65% 與 28% 時昂首咆哮並發出衝擊波，未及時迴避的獵人將陷入摀耳硬直！
   - **怒氣狂暴（Enrage）**：雙眼釋放紅光、移動速度與攻擊頻率大幅提升。
   - **部位破壞（Part Breaking）**：累積攻擊頭部可折斷龍角，攻擊尾部可切斷尾巴並大幅縮減其大迴旋甩尾判定半徑。
   - **失衡倒地（Stagger）**：累積衝擊傷害可使魔物大失衡翻肚倒地。
4. **獵人大劍連段與斬味系統（Sharpness）**
   - 輕斬三連段（縱斬 ➔ 橫掃 ➔ 上撈）與真・蓄力斬。
   - 斬味消耗與倍率（白斬 1.32x、藍斬 1.20x、綠斬 1.05x、黃斬 0.85x），可隨時使用砥石（按 R）研磨恢復！
5. **自由視野與目標鎖定（Target Lock-On）**
   - 按下 `Tab` 或 `F` 開啟視角鎖定，鏡頭平滑聚焦獵人與魔物之間的決鬥線。
   - 支援滑鼠右鍵拖曳環視自由視角。

## 🎮 操作說明

| 操作按鍵 | 動作指令 |
| :--- | :--- |
| **W / A / S / D** | 獵人移動 |
| **空白鍵 (Space)** | 翻滾閃避（具備無敵幀，可閃避龍車、甩尾與龍吼） |
| **J / 滑鼠左鍵** | 大劍輕攻擊三連斬 |
| **長按 K / 釋放** | 真・蓄力斬（長按集氣發光後釋放破壞性傷害） |
| **E** | 飲用回覆藥（+45 HP） |
| **R** | 使用砥石研磨（恢復最高斬味） |
| **Tab / F** | 開關目標鎖定（Lock-On）視角 |
| **滑鼠右鍵拖曳** | 自由旋轉 3D 相機視角 |

## 🚀 快速啟動

### 方式 1：直接開啟
雙擊打開本專案目錄中的 `index.html`，即可在任何現代瀏覽器（Chrome、Edge、Firefox、Safari）中暢玩。

### 方式 2：使用本機 PowerShell 靜態伺服器
執行本目錄內的指令檔：
```powershell
.\mh-3d-web.ps1
```
瀏覽器將自動開啟 `http://localhost:8080`。
