# 蒼林狩獵誌（3D 狩獵動作 Web 原型）

以 Three.js、Blender GLB 資產與原生 Web Audio API 製作的純前端原創 3D 狩獵動作遊戲原型：在被森林環繞的獵場中討伐大型甲獸「棘冠甲獸」。執行時不需要 Node.js、npm 或建置工具；Three.js、GLTFLoader 與顯示字型（Noto Serif TC、Cinzel）由 CDN 載入。

## 遊戲流程與介面

- **載入 → 標題 → 任務看板 → 進場演出 → 狩獵 ⇄ 暫停 → 終結慢動作 → 結算**，每個階段都有對應畫面。
- **標題畫面**：鏡頭繞獵場盤旋，提供開始狩獵、繼續狩獵（讀取存檔）、操作說明與設定，並顯示勝敗、最快討伐時間與最高評價。
- **任務看板**：羊皮紙任務單，列出目標、時限與失敗條件，並在出發前選擇大劍或雙劍。
- **狩獵 HUD**：
  - 左上：武器徽章（可點擊切換）、體力（含受傷殘影與瀕死警示）、耐力、四段色帶斬味、會心狀態。
  - 上方中央：目標名稱、體力條、頭角／尾部破壞狀態，以及狂暴、破綻、倒地、出招等狀態標示。
  - 右上：任務倒數計時、暫停鍵、隨鏡頭旋轉的小地圖。
  - 右下：回復藥與砥石道具欄（使用中會顯示環狀進度）；左下：可收合的操作提示。
  - 畫面中：鎖定準星、出招預警標記、魔物離開畫面時的方位指標、蓄力三段量表、連段標記、傷害數字、訊息欄與部位破壞字幕。
- **暫停選單**：繼續、操作說明、設定、儲存／讀取進度、放棄任務。切換到其他分頁時會自動暫停。
- **結算**：任務達成／失敗、S～C 評價印記、討伐時間、傷害、命中、弱點命中、部位破壞、承受傷害等統計，並標示是否刷新紀錄。
- **設定**（保存在 `localStorage`）：主音量、鏡頭靈敏度、鏡頭震動、介面大小、畫質，以及傷害數字、目標體力條、小地圖、操作提示的顯示開關。
- **觸控**：畫面左半為浮動類比搖桿、右半拖曳旋轉視角，右下為斬擊、蓄力、翻滾、鎖定按鍵。
- 選單支援鍵盤（方向鍵／`W` `S`、`Enter`、`Esc`）與滑鼠操作；HUD 以 `rem` 排版並隨視窗大小縮放，尊重 `prefers-reduced-motion`。

## 戰鬥系統

- 大劍與雙劍兩種武器：三段連斬、三段蓄力重斬、翻滾無敵時間、出招踏步與刀光拖影。
- **精準迴避**：在攻擊命中的瞬間以翻滾穿過，會觸發短暫慢動作、回復耐力並進入 6 秒「會心」狀態（傷害 ×1.25）。
- 斬味等級與傷害倍率：白斬 `1.32x`、藍斬 `1.20x`、綠斬 `1.05x`、黃斬 `0.85x`；磨刀與喝藥都需要時間，被擊中會中斷。
- 命中判定以魔物的脊椎線段區分頭部（弱點 ×1.35）、身體與尾部；可折斷頭角、切斷尾部（斷尾會飛落在地，甩尾範圍與傷害降低）。
- 魔物會追擊、衝撞、迴旋甩尾，累積傷害會失衡倒地，體力降至 65% 與 28% 時咆哮並狂暴 18 秒。
- 獵人無法穿過魔物身體、骨骸與倒木；獵場為圓形空地，擋住鏡頭的樹木與巨石會自動淡出。
- 任務時限 15 分鐘；體力耗盡或時間結束即任務失敗。
- 音效全部以 Web Audio API 即時合成（斬擊、命中、咆哮、風聲鳥鳴、介面與任務音效），不使用外部音檔。

## 操作方式

| 操作按鍵 | 實際動作 |
| :--- | :--- |
| `W` / `A` / `S` / `D` | 依目前相機方向移動獵人 |
| `Space` | 翻滾迴避，消耗耐力並提供短暫無敵時間 |
| `J` / 滑鼠左鍵 | 斬擊；在連段窗口內再次輸入可接續三段連斬 |
| 按住 `K` 後放開 | 依蓄力等級施放重斬 |
| `E` / `R` | 飲用回復藥（共回復 `45` 體力）／使用砥石 |
| `1` / `2` | 切換大劍／雙劍 |
| `F` / `Tab` | 鎖定／解除鎖定目標 |
| 滑鼠右鍵拖曳、滾輪 | 旋轉視角、調整鏡頭距離 |
| `Esc` / `P` | 暫停選單 |
| `H` | 顯示／收合操作提示 |

## 啟動

建議使用專案內的 PowerShell 啟動器，讓瀏覽器透過本機 HTTP 伺服器載入遊戲：

```powershell
pwsh -NoProfile -File .\mh-3d-web.ps1
```

啟動器預設監聽 `http://localhost:8080/`，並嘗試自動開啟瀏覽器。需要其他連接埠時可使用 `-Port`：

```powershell
pwsh -NoProfile -File .\mh-3d-web.ps1 -Port 5173
```

若只想啟動伺服器而不自動開啟瀏覽器，可加上 `-NoBrowser`。啟動器以 `$PSScriptRoot` 作為服務根目錄，只提供檔案、不建立或覆寫專案檔；按 `Ctrl+C` 可停止伺服器。若環境使用 Windows PowerShell，也可將 `pwsh` 替換為 `powershell`。

## 專案架構

```text
mh-3d-web/
├─ index.html                  # 頁面結構：HUD、各畫面與 SVG 圖示集
├─ styles/ui.css               # 介面樣式
├─ src/main.mjs                # Three.js 場景、遊戲流程、戰鬥與相機
├─ src/ui/hud.mjs              # HUD 繪製（量表、小地圖、訊息、傷害數字）
├─ src/ui/menus.mjs            # 標題／任務看板／暫停／結算／設定與鍵盤導覽
├─ src/ui/touch.mjs            # 觸控搖桿與動作鍵
├─ src/audio.mjs               # 程序化音效
├─ src/effects.mjs             # 火花與震波粒子
├─ src/game-rules.mjs          # 可獨立測試的戰鬥規則、命中判定與評價
├─ src/save-system.mjs         # 存檔、戰績與最佳紀錄
├─ src/settings.mjs            # 設定的正規化與保存
├─ tests/                      # Node 原生測試
├─ assets/models/              # Blender 匯出的 hunter.glb、monster.glb、hunting_ground.glb
├─ tools/generate_assets.py    # 以 Blender 背景模式重新產生 GLB 資產
└─ mh-3d-web.ps1               # 本機 PowerShell 靜態伺服器啟動器
```

## Blender 資產

模型由 Blender Python 腳本程序化產生，不依賴外部版權模型。腳本以 Three.js 慣例（+Y 朝上、+Z 朝前）建模，匯出時使用 `export_yup=False` 保留座標；圓柱與圓錐預設沿 Y 軸，需要朝前時傳入 `axis="z"`。重新產生資產：

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python tools\generate_assets.py
```

也可以用 `pip install bpy==5.2.3` 後直接以 Python 執行該腳本。`weaponPivot`、`dualWeaponPivot`、`weapon_blade`、`head`、`tail`、`horn_l`、`horn_r`、`tail_segment_*` 等節點名稱是遊戲整合的一部分，修改模型時請保留；重新產生後請更新 `src/main.mjs` 的 `assetVersion`。

## 技術備註

- `npm run check` 檢查所有模組語法、`npm test` 執行規則測試（需要 Node.js 20 以上）；修改遊戲邏輯後仍請在瀏覽器中實際操作確認。
- 若無法連線至 CDN，頁面會顯示錯誤訊息；字型載入失敗時會退回系統字型。
- 存檔格式與舊版相容：舊存檔缺少的任務進度會補 0，超出新獵場邊界的位置會被拉回場內。
