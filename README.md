# 3D 魔物獵人 Web 原型

這是一個以 Three.js 與原生 Web Audio API 製作的純前端 3D 動作遊戲原型。遊戲執行時不需要 Node.js、npm 或建置工具；主要畫面與遊戲迴圈在 `index.html`，共用規則則由 `src/game-rules.mjs` 提供。Three.js 由 CDN 載入。

## 目前功能

- 第三人稱 3D 場景、獵人與魔物模型、光照、陰影、霧效與場景邊界。
- 獵人移動、翻滾無敵時間、三段輕攻擊連段、依蓄力時間分級的重斬、回覆藥與砥石。
- 斬味等級與傷害倍率：白斬 `1.32x`、藍斬 `1.20x`、綠斬 `1.05x`、黃斬 `0.85x`。
- 魔物追蹤、龍車、迴旋甩尾、冷卻、倒地硬直，以及依血量門檻觸發的龍吼與限時狂暴。
- 頭部弱點、斷角與斷尾；尾巴被破壞後，甩尾攻擊範圍與傷害會降低。
- 以 Web Audio API 即時合成斬擊、命中、龍吼、翻滾、治療與研磨音效，不使用外部音檔。
- 命中火花、龍吼震波、短暫卡肉、鏡頭震動、傷害數字與勝負結算畫面。
- 目標鎖定與自由視角：鎖定時相機追蹤魔物，未鎖定時可用滑鼠右鍵拖曳旋轉視角。
- `P` 或畫面上的按鈕可暫停／繼續遊戲；失去視窗焦點時會清除輸入狀態。
- 小螢幕提供觸控方向鍵，以及攻擊、翻滾、蓄力與回復按鈕。

## 操作方式

| 操作按鍵 | 實際動作 |
| :--- | :--- |
| `W` / `A` / `S` / `D` | 依目前相機方向移動獵人 |
| `Space` | 翻滾閃避，消耗耐力並提供短暫無敵時間 |
| `J` / 滑鼠左鍵 | 輕攻擊；在連段窗口內再次輸入可接續三段連斬 |
| 按住 `K` 後放開 | 依蓄力等級施放重斬 |
| `E` | 飲用回覆藥，恢復 `45 HP` |
| `R` | 使用砥石，恢復至最高斬味 |
| `P` / 畫面上的「暫停」按鈕 | 暫停或繼續遊戲 |
| `Tab` / `F` | 開關目標鎖定 |
| 滑鼠右鍵拖曳 | 未鎖定時旋轉相機視角 |
| 觸控方向鍵／動作按鈕 | 移動、攻擊、翻滾、蓄力與回復 |

## 啟動

建議使用專案內的 PowerShell 啟動器，讓瀏覽器透過本機 HTTP 伺服器載入遊戲：

```powershell
pwsh -NoProfile -File .\mh-3d-web.ps1
```

啟動器預設監聽 `http://localhost:8080/`，並嘗試自動開啟瀏覽器。需要其他連接埠時可使用 `-Port`：

```powershell
pwsh -NoProfile -File .\mh-3d-web.ps1 -Port 5173
```

啟動器以 `$PSScriptRoot` 作為服務根目錄，只提供檔案、不建立或覆寫專案檔；按 `Ctrl+C` 可停止伺服器。若環境使用 Windows PowerShell，也可將 `pwsh` 替換為 `powershell`。

## 專案架構

```text
mh-3d-web/
├─ index.html                 # HUD、樣式、Three.js 場景與主要遊戲邏輯
├─ mh-3d-web.ps1              # 唯讀的本機 PowerShell 靜態伺服器啟動器
├─ package.json               # Node.js 檢查與測試命令
├─ src/game-rules.mjs        # 可獨立測試的戰鬥規則函式
├─ tests/game-rules.test.mjs # Node 原生測試
└─ README.md                 # 使用與功能說明
```

`index.html` 內的程式區塊目前依序包含程式化音效、粒子效果、Three.js 場景與模型、玩家狀態及輸入、魔物 AI、攻擊判定、相機、HUD 與主遊戲迴圈，並以 ES module 匯入 `src/game-rules.mjs`。外部執行期依賴是帶有完整性驗證的 CDN Three.js `r128`；若無法連線至 CDN，頁面會顯示載入錯誤，3D 遊戲畫面無法初始化。

## 技術備註

- `mh-3d-web.ps1` 使用 .NET `TcpListener` 綁定本機 loopback，僅接受 `GET` 與 `HEAD` 要求，並拒絕路徑穿越與服務根目錄外的路徑。
- `package.json` 要求 Node.js `20` 以上，可用 `npm run check` 檢查模組語法、`npm test` 執行規則測試；修改遊戲邏輯後仍請在瀏覽器中實際操作確認。
